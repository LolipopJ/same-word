# 会话、断线与生命周期

## 断线与恢复

刷新或短暂断线不暂停计时，也不延长作答时间。已提交答案继续有效；未提交者仍须在原截止时间前恢复，
到期即弃权。已弃权玩家可以查看进度，但不能重新参赛。

- 断线时禁止提交并保留当前页面的输入草稿。
- 同一会话的新标签页接管身份，旧标签页停止操作；旧标签页收到 `session:replaced`。
- 提交带确认与最多三次同请求重试，恢复以服务端快照为准。
- 未入房的邀请页面在断线时取消邀请检查，重连后重新检查有效性，并保留已输入的展示 ID。

## 身份

匿名 Cookie 在刷新后恢复原身份。单浏览器多个标签页共用身份，新标签页接管旧标签页。
展示 ID、客户端声明的 `playerId` 和 `socket.id` 都不作为凭据。

## 过期与清理

| 状态 | 保留时长 / 行为 |
| --- | --- |
| 准备阶段断线成员 | 身份保留 120 秒 |
| 终局后仍断线成员 | 从终局起重新保留 120 秒 |
| 空房间 | 立即销毁并取消计时器 |
| 无房间关联的匿名会话 | 连续闲置 24 小时后释放 |
| 房间的历史 | 只保留当前局及最近结束局，更早的历史与提交确认释放 |

## 重启

重启服务会立即清空全部状态。旧 Cookie 会获得新会话，旧邀请链接显示房间不存在或已失效。
发布、回滚或重启都会清空正在进行的房间；浏览器不会用本地草稿、分数或成员列表重建对局。

## 服务端日志

服务端控制台日志统一显示 ISO 时间、INFO／WARN／ERROR 级别与来源前缀，终端支持时为级别着色。
房间没有独立名称，以房间码作为前缀，例如 `[JAL7YH] Alice submitted round 1`。

记录内容包括服务启停、会话创建与过期、连接与接管、房间创建与销毁、成员和房主变更、配置、准备与倒数、
作答接受、弃权、轮次开始、超时、终局及失败操作；不记录高频状态同步、Cookie、会话令牌或答案正文。
不要将 Cookie 或 Socket.IO 负载写入访问日志。
