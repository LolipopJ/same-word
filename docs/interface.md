# 界面与交互细节

## 首页与离房

首次访问与刷新时，初始建连不显示重连横幅，页头为连接状态预留位置，避免正常建连时闪现警告或挤动控件。
390px 以下不展示“已连接”状态或为其占位；390px 及以上保留状态位置。连接失败、实际断线及身份被其他标签页接管时，仍显示对应提示和重新连接入口。

入房卡片标题右侧的“怎么玩？”按钮与标题垂直居中对齐，打开玩法对话框，展示规则与联想示例，可通过关闭按钮、Esc 或背景关闭。
首页右上方工具栏显示 GitHub 仓库图标按钮，邀请页与已入房页面不显示该入口。关闭 JavaScript 时，生产首页仍直接展示规则与示例。
工具栏的仓库、语言和主题按钮使用同一套 SVG 图标，保留随界面语言切换的可访问名称与悬停提示，触控区域至少 44×44px。

准备、对局与结果页面均可离开房间。点击页头品牌或“离开房间”时先显示同一个确认对话框；取消、Esc 或点击背景均留在房间，
只有确认才发送离房命令，服务端接受后返回首页。确认按钮在断线或请求进行中不可用，离房失败保留当前房间并显示错误。

## 响应式与触控

页面从 320px 单列布局开始，在宽屏扩展；页头和长文本可换行，主题弹层限制在视口内。
输入字号至少 16px，主要按钮和表单控件的触控区域至少 44×44px。操作区保持文档流，
底部为设备安全区域留白；准备进度和准备按钮位于完整成员列表之前，成员与房间设置可按需展开。
所有核心流程均可在无动画时完成。

## 信息层级

对局按轮次和时间、上轮线索、作答、玩家状态排序；大量线索先显示 4 条，明确入口可展开全部答案与归属。
展开线索或收到其他玩家状态时不重置草稿和焦点。结果先展示原因、共同词、人数、轮数与耗时，
个人返回按钮位于完整排名之前；并列积分、时间、弃权和最终答案均保留查看入口。

输入与提交保持原生表单和纵向滚动，错误与字段关联；桌面小视口检查不替代真实手机软键盘验收。

## 实时反馈与动效

准备确认、当前秒开局倒数、服务端接受作答、揭晓与新轮次提供短暂反馈；提交中单独显示等待，
失败保留草稿，不提前显示锁定或奖励。开局仍为 3 秒，普通揭晓仍为 5 秒，动画不增加等待。

实时成功时突出共同词和实际 +100，并以独立 canvas 播放一次有限彩带，成功轮不叠加 +1。
失败只保留真实原因、实际积分与柔和过渡。彩带不阻挡立即确认，2～3 秒内清理；
窄屏最多 60 个、宽屏最多 120 个粒子，两侧共享预算；部分同词的星点共享 12／24 个预算。

系统“减少动态效果”会停用位移、星点和彩带，保留分组、分数及完整操作；运行中开启会立即取消，
关闭不会补播。隐藏页面、断线、接管、确认返回或阶段失效都会清理效果；刷新、恢复、历史与参考不补播。

## 主题

页头调色盘图标按钮提供当前 daisyUI 版本的全部内置主题，可访问名称与悬停提示为“页面主题”。手动选择保存在本浏览器，刷新后继续使用。
默认选择“跟随系统”：浅色偏好使用 light，深色偏好使用 dark；系统偏好变化时自动切换。
选择“跟随系统”会清除手动选择。主题只影响本人的页面，不改变房间或其他玩家的设置。

## 界面语言

页头翻译图标按钮与主题按钮并列，可访问名称与悬停提示为“界面语言”，提供中文与 English。没有手动选择时，首次直接访问首页 `/` 固定中文，
与构建期正文、标题和文档语言一致；邀请入口按浏览器首选语言决定，以 `zh` 开头使用中文，其余使用英文。
手动选择保存在本浏览器，刷新后继续保留并优先于入口默认语言与浏览器语言；存储受限时首页仍默认中文。
语言只影响本人的页面，不改变房间状态、其他玩家的界面或服务端计时。

切换语言会同步更新根元素 `lang` 与页面标题，不清空输入草稿、不重发命令、不重播已结束的庆祝。
所有文案来自 `src/client/i18n/messages.ts` 的中英同结构语言包，英文缺键或参数不一致会在
`pnpm typecheck` 失败。错误提示只按服务端错误码选择本地化文案，服务端 `message` 仅用于日志，
不再直接展示；页面保留错误描述而非已翻译文本，因此切换语言时已显示的提示会同步改为新语言。
英文界面下的长按钮与提示在 320px 宽度内换行显示，主要触控区域仍不小于 44×44px。
