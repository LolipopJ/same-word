# 游戏规则

## 开局

1. 打开页面后设置展示 ID。展示 ID 与词语一致：1～20 个 Unicode 码点，不能包含换行或控制字符；同一房间内忽略大小写后必须唯一。
2. 一人创建房间，其余玩家输入 6 位房间码或打开邀请链接加入。
3. 房主在准备阶段设置容量、最多轮数和每轮时限。默认容量 8 人、最多 20 轮、每轮 60 秒。
4. 所有成员在线并点击准备后，倒数 3 秒开局，无须达到房间容量上限。等待中的未准备成员离开或过期移除后，也会按剩余成员重新检查开局条件。

邀请链接页面自动使用链接中的房间码，入房表单仅展示“展示 ID”和“加入房间”按钮，
不提供创建房间按钮或房间码输入。邀请失效时可通过“回到首页”重新创建房间或输入其他房间码。

## 房间配置

房主可在准备阶段设置整数配置：

- 容量 2～99，且不得低于当前成员人数；
- 最多轮数 2～999；
- 每轮 1～600 秒。

容量低于当前成员人数时，服务端以独立的 `CONFIG_BELOW_MEMBERS` 错误码返回，
客户端提示具体原因而非笼统的范围说明。保存配置会清除全员准备。
倒数期间不可加入、改名或改配置；对局中不可中途加入。

## 每轮玩法

1. 第一轮各自随意写一个词，计作第 1 轮。
2. 以后每轮参考上一轮的所有答案，寻找能连起来的词。
3. 每轮最多成功提交一次。全员提前提交立即揭晓，否则到期未答者弃权。
4. 作答隐藏至揭晓，成功提交后不可修改；非法输入保留重试机会且不会延长截止时间。
5. 揭晓后非终局持续 5 秒，再进入下一轮。

词语去除首尾空白并忽略大小写：`Apple` 与 `apple` 同词，`苹果` 与 `蘋果` 不同词；展示原文保留大小写。

### 历史词

本局之前任意玩家已成功提交并揭晓的词都不可重用，包括后来弃权者的答案。
历史词同样去除首尾空白并忽略大小写；失败提示为“发送失败：该词已在之前轮次出现”，
保留草稿、未答状态和原截止时间，可以改词重试。同轮相同的新词合法，新局清空禁词集合。

## 计分

- 非全员同词时，每个至少两人的同词组内每人 +1 分。
- 全员同词每人 +100 分，不再叠加 +1。
- 同房间可同时有多个同词组，各组独立计分。
- 最后一轮同词仍然成功；轮数用尽仍未同词，或有效玩家不足两人时失败。

已完成轮次的每个有效同词组都有编号、词语、人数及实际加分，并在对应答案上静态强调。
分组与分数直接取自服务端，大小写原文保留，结算前弃权者不计入；最后一轮部分同词后失败仍显示实际 +1。

## 弃权与离开

- 主动离开、放弃本局或到期未答只淘汰本人，不能在本局复活。
- 提交后、揭晓前弃权的答案仍会揭晓，但不参与本轮分组与加分；之前的积分保留。
- 揭晓后退出不重算积分。

## 结束与结果

剩余至少两人且全部同词即可成功。结果页显示结束原因、共同词、初始与有效人数、弃权、耗时、
开始／结束时间、已开始轮数和并列积分，并同时列出初始、完成与弃权人数。
人数不足时，未完成轮次也会展示已接受答案与未答情况，但不计本轮分数。

结果页每人独立确认返回，全员重新准备后开始新的一局。
个人确认结果不改变房间状态：他人可以返回和修改配置，下一局仍需全员在线且重新准备。
下一局的轮数、积分及词语历史重新初始化。

## 历史

历史入口支持当前局与最近结束局，每次最多 20 轮，也可从指定轮次读取；当前未揭晓答案不可查询。

## 房主

房主离开或断线时，按加入顺序转交给在线成员；无人在线则暂空缺，下一位重连者接任。
