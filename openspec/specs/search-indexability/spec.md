# search-indexability Specification

## Purpose

只将规范中文首页 `/` 作为搜索入口，为其提供可抓取的真实内容、统一的索引元数据与链接预览资源。其他 URL 输出排除索引信号或真实的未找到响应，并通过生产部署检查与搜索平台观察区分技术条件、实际收录和自然搜索流量。

## Requirements

### Requirement: 抓取许可与站点地图声明

系统 SHALL 在 `/robots.txt` 提供纯文本抓取许可文件，允许爬虫访问首页、依赖资源以及需要读取 `noindex` 的 URL，并声明站点地图的绝对地址。系统 MUST NOT 用禁止抓取代替禁止索引，也不得用首页 HTML 或重定向顶替该文件。

#### Scenario: 抓取器读取抓取许可

- **WHEN** 抓取器请求站点根路径的抓取许可文件
- **THEN** 返回 200 与 `text/plain` 内容，包含适用于所有爬虫的允许抓取规则，并给出指向站点地图的绝对地址

#### Scenario: 排除索引指令可被读取

- **WHEN** 遵循抓取许可的爬虫访问房间、接口或其他非首页 URL
- **THEN** 抓取许可不阻止该请求，爬虫能够读取响应中的排除索引指令

#### Scenario: 抓取许可文件缺失时的回退

- **WHEN** 该路径没有对应文件
- **THEN** 系统不得用首页 HTML 顶替，必须返回 404

### Requirement: 站点地图内容

系统 SHALL 在 `/sitemap.xml` 提供合法 XML 站点地图，始终只包含规范首页 `/` 一个绝对地址。站点地图 MUST NOT 纳入其他页面、房间、接口、静态资源、首页别名、查询参数变体或语言路由。

#### Scenario: 抓取器读取站点地图

- **WHEN** 抓取器请求站点地图
- **THEN** 返回 200、XML 内容类型与合法 XML，仅包含首页条目，且该地址与页面声明的规范地址完全一致

#### Scenario: 构建产物增加其他文件或路由

- **WHEN** 构建产物或应用中增加文件或路由
- **THEN** 站点地图仍只有规范首页一个条目，不自动扩大索引范围

### Requirement: 可索引 URL 边界

系统 SHALL 仅将路径 `/` 的首页作为可索引页面。首页响应 MUST NOT 包含 `noindex`；所有非首页 URL 的 HTTP 响应 SHALL 包含 `X-Robots-Tag: noindex`，且不得作为公开页面提交。静态文件仍可被抓取和用于首页渲染与链接预览，排除的是其自身作为独立搜索结果的索引。

#### Scenario: 首页可索引

- **WHEN** 抓取器请求站点首页
- **THEN** 返回 200，HTML 元数据与响应头均不包含禁止索引指令，且规范地址为公开来源的 `/`

#### Scenario: 房间链接不可索引

- **WHEN** 抓取器请求 `/rooms/:code`
- **THEN** 响应头包含 `X-Robots-Tag: noindex`，抓取许可不阻止读取该指令，且房间邀请和恢复功能正常

#### Scenario: 非首页接口与静态文件

- **WHEN** 请求 `/api/`、`/socket.io/` 的普通 HTTP 端点、`/health`、图标、分享图、发现文件或其他静态资源
- **THEN** 资源或接口按原用途响应，并携带 `X-Robots-Tag: noindex`；它们不进入站点地图或主动提交清单

#### Scenario: 首页文件别名

- **WHEN** 外部请求 `/index.html`
- **THEN** 返回指向 `/` 的永久重定向和 `X-Robots-Tag: noindex`，不以 200 提供第二个首页入口

#### Scenario: 首页查询参数

- **WHEN** 请求带查询参数的首页
- **THEN** 页面规范地址仍为无查询参数的 `/`，站点地图和提交清单不产生参数变体

### Requirement: 未知路径返回未找到

系统 SHALL 对既不是现有接口或静态资源、也不匹配首页或合法房间链接的路径返回状态码 404，而不是返回首页内容。两种托管方式 SHALL 采用相同的六位大写房间码格式约束；错误响应同样 MUST 包含 `noindex`。

#### Scenario: 拼写错误的路径

- **WHEN** 请求 `/abcd` 这类既非首页也非房间链接的路径
- **THEN** 返回 404 与 `X-Robots-Tag: noindex`，不返回首页 HTML

#### Scenario: 房间链接仍然可用

- **WHEN** 请求形如 `/rooms/ABCDEF` 的房间链接
- **THEN** 正常返回邀请页面，不因回退规则收窄而失效

#### Scenario: 无效房间格式与语言路由

- **WHEN** 请求 `/rooms/abc`、`/rooms/abcdef`、`/rooms/ABC`、`/en/` 或其他未定义页面
- **THEN** Nginx 与 Node 生产预览均返回 404 和 `X-Robots-Tag: noindex`

### Requirement: 生产公开来源

生产构建 SHALL 使用唯一的真实 HTTPS 公网来源生成首页规范地址、站点地图、分享地址与结构化数据。缺失、非法、本地地址或示例占位来源 MUST 导致生产构建失败；来源不得包含用户名、密码、非根路径、查询参数或片段。

#### Scenario: 配置真实来源

- **WHEN** 生产构建获得合法的公开来源配置
- **THEN** 所有索引与分享地址使用该来源，首页地址统一为以 `/` 结尾的绝对 URL

#### Scenario: 未配置或使用占位来源

- **WHEN** 生产构建没有来源配置，或来源为本地地址、非 HTTPS 地址、示例域名或非法 URL
- **THEN** 构建失败并指出公开来源配置问题，不生成可供误发布的本地或占位索引地址

### Requirement: 首页索引元数据

系统 SHALL 为首页提供中文标题、中文描述、唯一的绝对规范地址与 `zh-CN` 文档语言，且这些值 MUST 在 HTML 交付时即已存在。标题和描述 SHALL 自然说明品牌与多人联机文字联想游戏的用途，不以非空或关键词堆砌作为内容验收。

#### Scenario: 抓取器读到元数据

- **WHEN** 抓取器获取首页 HTML 而不执行脚本
- **THEN** 能读到中文品牌与游戏类型、玩法摘要、绝对规范地址和 `zh-CN` 文档语言

#### Scenario: 规范地址与来源一致

- **WHEN** 站点部署在构建时声明的公开地址
- **THEN** 规范地址、站点地图条目与分享图地址使用同一来源，不混用相对路径

#### Scenario: 默认首页执行脚本

- **WHEN** 没有手动语言偏好的全新浏览器直接访问首页，首选语言分别为 `zh-CN` 或 `en-US`，并执行 JavaScript
- **THEN** 默认首页正文、标题与文档语言均保持中文；不按 User-Agent 为爬虫提供不同版本

### Requirement: 构建期可见正文

系统 SHALL 在构建产物中包含首页可见的主标题、游戏介绍、规则说明与至少一个文字联想玩法示例，明确回答这是什么游戏、如何邀请朋友及如何达到同词目标。标题层级 SHALL 使用语义标签，正文与正常中文用户所见一致，并来自同一语言包。

#### Scenario: 不执行脚本的抓取器

- **WHEN** 抓取器获取首页 HTML 且不执行 JavaScript
- **THEN** 页面正文包含中文主标题、游戏类型、邀请说明、规则与玩法示例；仅凭静态 HTML 即可理解游戏用途

#### Scenario: 脚本正常执行后的用户体验

- **WHEN** 浏览器加载页面并执行脚本
- **THEN** 正文不重复出现，所选语言的说明和示例仍可见，游戏交互保持可用，语言切换遵循 `client-localization` 的要求

#### Scenario: 文案来源唯一

- **WHEN** 语言包中的首页文案被修改
- **THEN** 构建产物中的正文随之更新，无需在别处另行维护同一段文案

### Requirement: 链接预览元数据

系统 SHALL 为首页提供 Open Graph 与 Twitter 卡片的中文标题、描述、类型与分享图，并提供图片替代文字。分享图 MUST 使用与首页同源的绝对地址，引用的资源 MUST 存在于发布产物中。

#### Scenario: 预览服务读取首页

- **WHEN** 预览服务获取首页 HTML 和分享图
- **THEN** HTML 直接提供完整的卡片元数据，分享图返回 200、正确图片类型与可读的中文图像内容

#### Scenario: 分享图缺失

- **WHEN** 发布检查发现分享图缺失或引用地址无法访问
- **THEN** 发布验收失败，不以平台可能显示文字卡片代替资源完整性要求

### Requirement: 站点图标与安装元数据

系统 SHALL 提供浏览器标签页图标、供移动端主屏使用的图标，以及声明应用名称与图标的 Web App Manifest。

#### Scenario: 搜索结果显示站点图标

- **WHEN** 站点出现在搜索结果中
- **THEN** 能取到可访问的站点图标，且图标以矢量源文件为唯一设计来源

#### Scenario: 添加到主屏

- **WHEN** 用户在移动端把站点添加到主屏
- **THEN** 使用 Manifest 声明的名称与图标，图标地址可访问

### Requirement: 首页结构化数据

系统 SHALL 在首页提供机器可读的结构化数据，说明该站点是一个中文在线游戏应用，且其中的地址、名称和用途 MUST 与可见品牌、页面内容及规范地址一致。结构化数据不得声明未提供的功能，也不作为搜索引擎一定展示特殊结果的保证。

#### Scenario: 解析结构化数据

- **WHEN** 抓取器解析首页的结构化数据
- **THEN** 能得到网页应用类型、品牌名称、中文语言与其规范地址，且与可见内容和页面元数据不矛盾

#### Scenario: 结构化数据与页面不一致

- **WHEN** 名称或地址与页面元数据不一致
- **THEN** 该不一致被视为缺陷，必须以页面元数据为准确来源修正

### Requirement: 静态资源压缩传输

Nginx 生产托管 SHALL 对 HTML、脚本、样式、站点地图与文本类资源启用 gzip 压缩，且压缩 MUST 不改变资源内容与缓存策略。Node 本地生产预览不承担压缩要求，但须满足相同的路由与索引边界。

#### Scenario: 脚本以压缩形式传输

- **WHEN** 支持 gzip 的浏览器通过 Nginx 请求首页脚本
- **THEN** 响应使用压缩编码，且解压后的内容与构建产物完全一致

#### Scenario: 图片类型区别处理

- **WHEN** 浏览器请求图标
- **THEN** PNG 不重复启用 gzip，SVG 可作为文本压缩，解码后的内容均与原文件一致

### Requirement: 中文搜索上线与效果验证

上线验收 SHALL 分别记录技术可抓取条件、实际收录与搜索效果。检查 SHALL 覆盖大陆网络和移动端、百度搜索资源平台及 Bing Webmaster Tools；仅提交规范首页，按实际权限使用链接或站点地图提交。搜索引擎处理结果 MUST 作为观察记录，不得把提交成功等同于已收录、排名或获得流量。

#### Scenario: 生产抓取检查

- **WHEN** 站点发布到配置的公开来源
- **THEN** 记录大陆网络和移动端访问、首页有无 JavaScript 的内容、发现文件、依赖资源，以及首页和非首页响应的状态码与索引指令；请求不依赖登录或交互式验证

#### Scenario: 仅首页提交

- **WHEN** 在目标搜索引擎平台验证站点并提交链接或站点地图
- **THEN** 提交范围只有规范首页，记录平台、时间、方式与结果；没有相应权限或入口时明确记录限制，不提交其他路由

#### Scenario: 上线后的观察

- **WHEN** 技术发布后检查搜索效果
- **THEN** 记录首页抓取与索引状态、非首页是否被误收录、中文目标查询的展现与点击；无数据时记录无数据，未收录时保留抓取诊断及待处理事项
