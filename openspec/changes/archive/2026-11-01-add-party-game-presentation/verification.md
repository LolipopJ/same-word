# Verification

## 静态基础与准备房间

- 使用本机 Edge 无头浏览器和独立 Cookie 会话，连接本地 Vite 与真实服务端。
- 320／360／390／1280px，light／dark：首页无横向溢出，主要输入、按钮与主题选项均至少 44×44px，主题弹层完整位于视口内。
- 普通首页：空展示 ID 返回可见错误；20 码点展示 ID 可创建房间。
- 有效邀请：仅展示 ID 与加入操作，无创建入口或房间码输入；第二独立会话成功加入。
- 失效邀请：显示失效提示和回首页入口，320px 无横向溢出。
- 两人全员准备后出现倒数，取消准备立即回到真实准备进度。
- 房主保存容量 99 后全员准备被清除；97 个独立 Socket.IO 会话加入，两浏览器会话共 99 人，完整名单可展开且无横向溢出，准备按钮在名单之前。
- 99 人全员准备后开始倒数，取消后显示 98／99。此阶段尚未添加动效，以上流程均以静态页面完成。

## 静态对局与结果

- 99 人真实对局：两个部分同词组各 2 人、每人 +1；揭晓、下一轮参考、历史的答案文本与归属一致。成功结果与历史也完全一致，挂载无粒子或庆祝。
- 320px 第二轮：4 条预览、完整 99 条可展开，线索位于输入之前；展开／收起不清空草稿，无横向溢出。
- 99 人轮数耗尽：99 人开始、98 人完成、1 人弃权；并列排名、主动弃权的轮次、完整时间可查看，返回按钮先于长明细。本人确认后另一会话仍在结果页。
- 两人首轮成功与人数不足：原因、人数、轮数、耗时与真实结算一致，未完成轮次显示 +0。
- 320×360 短视口：另一玩家提交时保留草稿、光标、焦点及滚动位置；历史词提交返回关联错误，草稿保留，修改后可提交并锁定。

## 环境限制

- 桌面视口模拟不能证明真实手机软键盘、刘海与手势安全区域的行为；本环境没有连接真实移动设备，这些项目保留未验证记录。
- 无头 Edge 中把另一个标签页置前，原页仍报告可见；页面隐藏取消通过真实 DOM 的可见性事件模拟与纯转换测试验证，未冒充真实后台切换验收。

## 实时反馈与预算

- 表现转换定向用例覆盖初始化、换连接代次、重复版本、直接成功／失败、参考重挂载、个人确认、新一局、后台／断线／减少动态效果及未完成轮次。
- 准备和提交确认只来自服务端已接受快照；空提交不锁定。倒数显示当前秒、不在 live region 逐秒播报，取消立即移除。99 人揭晓使用一个 600ms 入场，下一轮随原 5 秒服务端截止切换。
- 苹果／苹果／香蕉／香蕉／梨：两个组各自显示 2 人、每人 +1；四张有效答案同步轻弹，梨为 +0。
- Apple／apple 与结算前弃权的 APPLE：只庆祝有效 2 人，保留大小写原文，弃权者 +0。揭晓后退出不改变已结算分组。
- 最后轮部分同词直接失败：保留实际 +1 和局部轻弹，无成功彩带。
- 99 人、48 个组：320px 共 12 星点，1280px 共 24 星点，单次 700ms；所有分组仍有编号、静态对应与实际分数。运行中开启减少动态效果立即移除星点，关闭不重播，结果分组仍完整可见。
- 首轮成功：5 人开始、3 人完成、2 人弃权，实际每人 +100；一个 canvas，无同轮 +1 动效。
- 浏览器实际绘制统计：窄屏每帧 60 粒子、宽屏 120；canvas 生命周期约 2622ms，指针行为为 none。立即确认、减少动态效果、真实断线、接管均移除 canvas，恢复不重播；模拟隐藏事件同样取消。
- 使用临时 pnpm 12.16.1（项目要求 >=12）安装 canvas-confetti 1.9.4 与类型 1.9.0，Vite 使用包内 dist/confetti.module.mjs；未新增其他运行时动画或 UI 框架。
- `pnpm build` 成功，包含客户端／服务端类型、浏览器导入边界和生产浏览器打包。后续仅做排版、初始化方式与 ref 命名清理，按任务约定不重复已通过构建。
