## 4. 索引边界与路由

- [x] 4.1 改写 `deploy/nginx.conf`：首页和符合 `^[A-Z2-9]{6}$` 的房间路径在当前 location 以 `try_files /index.html =404` 提供文件；外部 `/index.html` 以 301 归并到 `/`，其他静态请求只查实际文件，保留接口反代并移除全路径首页回退；验证方式是 `nginx -t` 通过且别名重定向不形成循环

- [x] 4.4 比对两条托管链路的路由矩阵，覆盖 `/`、首页参数变体、`/index.html`、合法房间、失效但格式合法的房间、`/rooms/abc`、`/rooms/abcdef`、`/unknown`、`/en/`、发现文件、接口和静态文件；验证方式是逐项核对 GET/HEAD 状态、重定向位置与 `noindex`，且合法邀请仍能加入
