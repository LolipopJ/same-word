# Proposal

## Why

当前客户端所有可见文案都以中文字面量直接写在组件里，服务端也把中文提示当作 `Ack.message` 返回。非中文使用者无法使用该游戏，而把文案散落在各组件里也使后续增改语言必须逐处修改。需要让页面在中文与英文之间切换，并把文案集中到可校验的语言包中。

## What Changes

- 在页头增加语言选择，与现有主题选择并列：提供中文与英文两种界面语言。
- 默认跟随浏览器语言（`zh*` 使用中文，其余使用英文），手动选择保存在当前浏览器，刷新后保留；语言只影响本人页面。
- 将客户端所有用户可见文案（页面标题、页头、表单标签与占位符、按钮、状态、提示、错误、无障碍名称、规则说明、结果与历史文案）迁入带类型约束的语言包，组件只引用文案键。
- 客户端改为按错误码生成提示，不再直接显示服务端返回的中文 `message`；服务端 `message` 仅用于日志与排错，未知错误码使用通用本地化提示。
- 日期、时间、时长与数字按当前界面语言格式化；`<html lang>` 与页面标题随语言更新。
- 语言切换 SHALL 不改变房间状态、不清空输入草稿、不重播已结束的庆祝，并在 320px 窄屏下保持英文长文案完整可读。

## Capabilities

### New Capabilities

- `client-localization`: 拥有界面语言的选择与持久化、文案集中管理、错误提示的语言无关化、区域相关格式化，以及语言切换与窄屏文案完整性的约束。

### Modified Capabilities

无。房间、轮次、结果、会话与既有表现规格的可观察游戏行为保持不变；语言支持集中在新的 `client-localization` 能力中。

## Impact

- 主要涉及 `src/client`：新增语言包与语言上下文，修改 `main.tsx`、`App.tsx`、`home-screen.tsx`、`game-screen.tsx`、`lobby-screen.tsx`、`lobby-settings.tsx`、`results.tsx`、`history.tsx`、`round-answers.tsx`、`invite-status.tsx`、`theme-switcher.tsx` 与 `index.html`。
- 不修改 `src/shared/protocol.ts` 的命令、错误码或快照结构；不修改服务端业务规则、计时、计分、隐私与日志格式。
- 服务端现有中文 `message` 保留为诊断信息，客户端不再展示；`session-recovery` 与其他规格中的错误码契约不变。
- 新增最小客户端定向测试，校验两种语言的语言包键集合一致且每组错误码都有对应提示；同步 README 的语言切换说明。
- 本次不包含第三种语言、服务端多语言日志、按房间统一语言、URL 语言前缀或语言相关的协议字段。
